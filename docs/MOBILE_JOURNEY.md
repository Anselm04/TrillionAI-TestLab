# Mobile journey foundation

The declarative schema supports launch, text tap, visible and not-visible assertions, and stop. The Maestro compiler emits JSON-compatible YAML with escaped exact-match selectors. Arbitrary scripts and interpolation are not supported. A trusted execution callback returns command outcomes bound to declared build and flow hashes. These hashes do not authenticate the build or prove independent execution.

The actual Maestro process adapter and integration into the leased Android worker before uninstall are outstanding. No physical device execution or independent verification is claimed. Offline tests cover schema and compiler behavior. Only synthetic accounts and sandbox environments are permitted.
