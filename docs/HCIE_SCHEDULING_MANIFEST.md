# HCIE independent scheduling manifest
Derives the expected ordered map-task digest from the independently sealed inventory and per-file chunk manifests, without reading the queue. Verifies complete byte-range coverage, recomputes chunk manifest digests, enforces bounded cursor pages and task quotas, and reports excluded/unavailable/empty files explicitly. The caller must supply the expected inventory digest from trusted independent intake evidence. Queue insertion must follow canonical inventory path and chunk ordinal order to match this digest. An empty expected task set is reported but is not yet supported by the existing reduction store. This function rescans on interruption; persistent end-to-end coordination remains next. No claim of complete testing, distributed scale, or live model execution.
