# HCIE local analysis worker
The trusted local worker claims a fenced queue task, retrieves the exact sealed source bytes, checks descriptor and policy binding, invokes a read-only analyzer and persists bounded analysis observations. Capacity denial, source corruption, malformed output and cancellation cannot produce successful analysis. Interrupted leases are recovered by the queue. The callback is a trusted integration point, not an implemented AI model or independent proof of correctness. Abort is cooperative; hard isolation, resource enforcement, remote authentication and distributed operation still need supervisor infrastructure. No live model calls, dependencies or production activation.
