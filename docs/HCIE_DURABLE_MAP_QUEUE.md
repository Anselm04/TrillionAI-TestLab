# Durable HCIE map queue
A revision- and policy-bound SQLite queue schedules sealed chunk descriptors in bounded pages. Stable task IDs prevent duplicate enqueue; a durable quota bounds the task count. Atomic claims issue expiring fencing tokens; expired claims retry only within the configured attempt budget and then become INCOMPLETE. Results must bind the exact chunk identity, hash and policy. The queue exposes analysis observations only, never test verdicts or complete repository coverage.

This is a local trusted-coordinator primitive. Distributed worker authentication, execution supervision, hard resource deadlines, evidence verification and persistent reduction remain separate work. Leases use the coordinator wall clock; workers cannot be allowed to control that clock. Expired work is reconciled on claim. No customer source edits, new paid dependencies or production activation. Prior verified-byte-reader changes are included in this branch ancestry and must pass CI before merge.
