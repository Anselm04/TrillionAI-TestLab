# HCIE local pipeline coordinator
Coordinates an independently sealed inventory through persistent chunk indexing, independent expected task manifest derivation, canonical paginated queue insertion, verified-byte map execution and persistent hierarchical reduction. Each local step persists a phase/cursor or uses idempotent underlying stores. A restart replays the last uncommitted step. Empty task sets are explicit non-certifying reports. Coverage gaps and incomplete map outcomes remain visible.

The coordinator deliberately does not assert analysisComplete or testingComplete. It assumes dedicated operator-protected local databases, one active supervisor, immutable inventory, and a trusted read-only analyzer. Manifest derivation can rescan the full inventory; worker abort is cooperative, not hard sandbox enforcement. The supplied inventory must already be independently sealed; customer intake, authenticated distributed execution, evidence review, resource isolation and scale qualification remain outstanding. No paid service, live model call or production activation.
