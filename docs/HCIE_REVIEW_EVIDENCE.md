# Durable HCIE review evidence
Accepted analysis must include a reviewer identifier, reviewer-definition digest and exact observation/source binding. Queue completion stores this evidence atomically with the result, validates it on retrieval, and reduction preserves it in the leaf record. Direct completion without review evidence fails. Existing unreviewed ANALYZED queue records fail validation rather than acquiring retrospective approval. Use fresh queue and reduction databases for this policy; old sealed reductions are not retroactively validated. Reviewer identity is asserted by the trusted local callback, not authenticated or signed. Independent agent registration, policy allowlists, isolated execution and semantic verification remain outstanding. No live calls or deployment.
